# 🛡️ Insider Threat Detection System

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![Streamlit](https://img.shields.io/badge/Streamlit-1.28%2B-red)
![License](https://img.shields.io/badge/License-MIT-green)

Advanced insider threat monitoring and detection system with real-time alerts, automated email notifications, and comprehensive reporting.

## ✨ Features

### 🚨 Real-time Threat Monitoring
- Continuous monitoring of user activities
- Automated detection of suspicious behavior
- Real-time threat scoring and classification

### 📧 Automated Email Alerts
- Immediate email notifications for critical threats
- Configurable alert thresholds
- Professional HTML email templates
- Cooldown mechanism to prevent spam

### 📊 Interactive Dashboard
- Real-time threat visualization
- Department-wise analysis
- Risk score tracking
- Historical trend analysis

### 📈 Advanced Reporting
- HTML and Excel report generation
- Executive summaries
- Compliance reporting
- Custom report templates

### ⚙️ System Configuration
- Email alert configuration
- Database integration (PostgreSQL)
- User management
- Customizable alert rules
